Pemasangan Website Daarul Fikr

Ikuti 4 langkah. Halaman ini membuatkan file yang Anda butuhkan.

1Buat proyek Firebase

  1. Buka console.firebase.google.com dan login dengan akun Google.
  2. Add project → beri nama → selesai.
  3. Build → Firestore Database → Create database → lokasi asia-southeast2 (Jakarta) → mode production.
  4. Build → Authentication → Get started → Email/Password → Enable. Tab Users → Add user: buat akun admin (email + password kuat). Catat emailnya.
  5. Project settings (roda gigi) → Your apps → ikon Web </> → daftarkan app. Salin kode firebaseConfig yang muncul.

2Buat firebase-config.js

Tempel kode firebaseConfig dari Firebase di bawah ini.




3Buat aturan keamanan (Rules)


Masukkan email admin yang Anda buat di langkah 1.




Lalu buka Firestore Database → tab Rules, hapus isinya, tempel, klik Publish.





4Upload dan aktifkan


  1. Upload ke hosting: index.html, admin.html, ortu.html, db.js, konten.js, konten-default.js, site-config.js, firebase-config.js (hasil langkah 2), logo.png, dan favicon.png. Pilihan hosting ada di PANDUAN.md (Firebase Hosting, Netlify, atau cPanel).
    2. 

  2. Di Firebase: Authentication → Settings → Authorized domains → Add domain → isi alamat website Anda.
    3. 

  3. Buka alamat-anda/admin.html, login, isi Pengaturan Situs, lalu klik Muat data contoh di tab Program dan Jadwal.
    4. 

  4. Uji daftar dari HP, terima di admin, lalu cek status.
